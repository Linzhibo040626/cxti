# CSTI Bilibili Promo Video

这里是一版可录屏成 MP4 的 B 站推广视频页面。

## 使用方式

1. 打开 `csti-bilibili-promo.html`。
2. 浏览器缩放设为 100%。
3. 建议全屏后录制，画面比例为 9:16。
4. 点击“重播”，再点击“隐藏按钮”。
5. 用系统录屏、剪映录屏或 OBS 录制 92 秒。
6. 导出 MP4 后上传 Bilibili。
